# Why adding SA and G adjoints helps:
# It fixes the main inconsistency: your forward state uses SA + penalized wall-distance, but your gradient mostly ignores their coupling.
# You can do this without making the forward solve monolithic.

# So what’s the next step after adding SA and G adjoints?
# If done properly, that is already the major step.
# The next step after that is usually validation, not immediately “more coupling”.

# Practical roadmap (best path):
# 1. Add SA adjoint first (keep G frozen).
# 2. Add G adjoint (Eq. 25 residual adjoint).
# 3. Build a coupled adjoint system for [lambda_NS, lambda_SA, lambda_G] at the converged forward state.
# 4. Use the full design gradient from all residuals.
# 5. Validate with finite-difference checks on a coarse mesh.
