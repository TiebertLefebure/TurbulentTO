This appendix collects the detailed setup information that would interrupt the results narrative in Chapter~\ref{ch:benchmark_results}. It includes the geometry, boundary-condition, physical, numerical, and validation-mesh settings for the benchmark cases. The Dilgen pipe bend is included as a sensitivity verification case. The Dilgen U-bend, Alexandersen pipe bend, and Yoon diffuser are the three true topology optimization cases and therefore include Ansys grid-independence tables for the extracted geometries.

\section{Validation and Meshing Strategy}
\label{sec:app_B_mesh_strategy}
For the three extracted topology optimization designs, the Ansys validation meshes are refined through coarse, medium, and fine resolutions. The reported validation metrics in Chapter~\ref{ch:benchmark_results} should be taken from a mesh for which both viscous dissipation and pressure drop have become insensitive to further refinement. The final thesis should report the selected mesh explicitly for each case.

Both SA and SST $k$-$\omega$ validation runs should use the same extracted geometry, inlet condition, outlet condition, and fluid properties. The mesh-independence comparison should be performed for each turbulence model because the near-wall and separated-flow predictions can respond differently to grid refinement.

\section{Wall-Distance and Penalization Conventions}
\label{sec:app_B_wall_distance_conventions}
The benchmark set uses more than one wall-distance convention. Table~\ref{tab:app_B_wall_distance_modes} records these implementation choices so that the results can be interpreted without assuming a single global wall-distance equation.

\begin{table}[htbp]
	\centering
	\footnotesize
	\caption{Wall-distance and SA wall-source conventions used by the Chapter~\ref{ch:benchmark_results} benchmarks.}
	\label{tab:app_B_wall_distance_modes}
	\renewcommand{\arraystretch}{1.2}
	\begin{tabularx}{\textwidth}{l X}
		\hline
		\textbf{Case} & \textbf{Implementation note} \\
		\hline
		Dilgen pipe bend & Uses the \texttt{poisson\_penalized} wall-distance mode. The SA wall-density source must still be recorded after the final fixed-geometry sensitivity script is frozen. \\
		Dilgen U-bend & Uses the \texttt{poisson\_penalized} wall-distance mode with a design-driven SA wall source, because the evolving material field defines the turbulent wall. \\
		Alexandersen pipe bend & Independent pipe-bend topology optimization case. Record the exact wall-distance mode and SA wall-source option used by the working implementation. \\
		Yoon diffuser & SA benchmark following the reciprocal/Yoon-style wall-distance logic of Yoon~\cite{Yoon2016}. Record the exact implementation option in the final parameter table. \\
		\hline
	\end{tabularx}
\end{table}

The final methodology chapter should state these alternatives explicitly. In particular, the Dilgen-style cases should not be described as if they used the same reciprocal wall-distance equation as the Yoon-style cases.
