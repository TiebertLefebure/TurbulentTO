## TurbulentTO: Topology Optimization for Turbulent Flows

**TurbulentTO** is a custom finite-element computational fluid dynamics (CFD) and topology optimization framework built in [FEniCS](https://fenicsproject.org/). It is designed to optimize high-speed fluid manifolds in the turbulent regime to minimize total pressure drop. The framework couples a highly stabilized **Spalart-Allmaras (SA) one-equation turbulence model** with advanced continuous adjoint sensitivity solvers.

## Repository Structure

* **`TurbulenceModels/`**: The standalone SA fluid dynamics engine. Includes the IPCS fractional-step solver, SUPG stabilization, and a PDE-based relaxed Eikonal wall-distance solver.
* **`FluidTO/`**: The core topology optimization architecture. Contains the continuous adjoint solvers, Brinkman penalization, density filtering, and MMA execution loops.

*(Note: Both directories contain dedicated `Meshes/` folders with the `Gmsh` Python scripts required to generate the boundary-layer-resolved grids for the solvers).*

## Key Features

* **Wall-Resolved Turbulence:** Integrates directly through the viscous sublayer without empirical wall functions, ensuring stability as solid boundaries evolve.
* **Dual Adjoint Formulations:** Features a robust "Frozen Turbulence" baseline for highly stable optimization, alongside an experimental "Semi-Frozen" monolithic formulation that couples turbulence transport sensitivities.
* **Mass-Conserving Filtering:** Implements a Discontinuous Galerkin (DG0) Helmholtz filter using interior facet jump penalties to strictly prevent numerical mass leakage across boundaries.
* **Independent CFD Validation:** Topologies generated by this framework have been independently cross-verified in **Ansys Fluent** ($k-\omega$ SST) to confirm significant aerodynamic performance gains over traditional laminar-assumed designs.
